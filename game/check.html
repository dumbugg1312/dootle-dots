CHECK A RUN CODE

Every Dootle Dots speedrun card has a run code. Type it in to see the category, time and date it was made for. If the card says something different, someone edited it.

A code only shows that the time on the card wasn't typed over. The game runs in your browser, so a code can't prove a run was played fairly. That takes a video.

Play Dootle Dots. To speedrun without beating the game first, go to OPTIONS, turn UNLOCK ALL LEVELS on, then pick SPEEDRUN on the title.
